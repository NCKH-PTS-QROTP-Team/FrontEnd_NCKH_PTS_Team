## 🎨 Cách sử dụng

1. Mở Figma Desktop hoặc Figma Web
2. Tạo một file mới hoặc mở file hiện có
3. Kéo thả các file SVG từ folder này vào canvas
4. Các file SVG đã được tối ưu cho Figma với:
   - Kích thước: 1440x900 (hoặc tương ứng)
   - Màu sắc: Theo design system
   - Layout: Giống với code React Native

## 📐 Kích thước

- Desktop: 1440 x 900 pixels (mặc định)
- Một số màn hình dài hơn sẽ có height lớn hơn

## 🎯 Màu sắc sử dụng

- Primary: `#3FA9F5`
- Success: `#10B981`
- Warning: `#F59E0B`
- Error: `#EF4444`
- Gray Scale: `#F9FAFB` → `#111827`

## 📝 Lưu ý

- Các file SVG được tạo thủ công dựa trên code React Native
- Layout và spacing được giữ nguyên từ code
- Một số chi tiết có thể được đơn giản hóa để phù hợp với SVG
- Tất cả text đều sử dụng font Arial (có thể thay đổi trong Figma)
