# Assets Folder

Thư mục này chứa các assets cho ứng dụng Expo.

## Files cần thiết (có thể tạo sau):

- `icon.png` (1024x1024) - App icon
- `splash.png` (1284x2778) - Splash screen
- `adaptive-icon.png` (1024x1024) - Android adaptive icon
- `favicon.png` (48x48) - Web favicon (optional)

## Tạm thời

Expo sẽ tự động tạo placeholder cho các file này nếu chưa có.
